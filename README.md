# Portfolio

Single-page responsive portfolio built with React and Tailwind CSS.

## Sections

- **Hero** — Bold headline and primary CTAs
- **About Me** — Technical PM background and skill highlights
- **Projects** — Responsive 3-column grid with placeholders

## Run locally

```bash
cd C:\Users\prach\Downloads\Projects\Website
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```
